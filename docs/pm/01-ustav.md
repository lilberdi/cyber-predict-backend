# Устав проекта Cyber Predict

**Дисциплина:** Управление проектами  
**Срок:** 12 недель, команда 4 человека  
**Горизонт этого файла:** недели 1–4 выполнены в репозитории

## Название

Интеллектуальная система прогнозирования результатов киберспортивных матчей (Counter-Strike 2).

## Цель

Прототип, который для предстоящих профессиональных матчей CS2 считает вероятность победы команды и показывает её через REST API (далее — в UI).

## Критерии успеха

- Прогноз на реальные upcoming (PandaScore) или на фикстуры защиты.
- Метрики модели и сравнение с Elo-фаворитом.
- Отказ от парсинга HLTV обоснован.
- Есть устав, WBS, график, риски, RACI.
- Демо через Docker Compose.

## Ограничения

Только CS2. Без ставок, аккаунтов и мобильного приложения. HLTV не скрейпится (ToS п. 2.2).

## Допущения

Бесплатный PandaScore отдаёт календарь. Историю можно временно заменить синтетическим sample. Accuracy 55–65% приемлема.

## Deliverables к неделе 4

- Документы PM (этот каталог + Word).
- Go/Gin API + PostgreSQL + миграции + OpenAPI.
- Python: sample history, Elo + logreg, sync upcoming, запись прогнозов.
