# Стейкхолдеры, роли и RACI

## Стейкхолдеры

| Стейкхолдер | Интерес | Влияние | Ожидание |
|---|---|---|---|
| Преподаватель | Оценка PM | Высокое | Документы, сроки, решения |
| Команда (4) | Прототип и сдача | Высокое | Ясные роли |
| Пользователь-фан CS2 | Понятный прогноз | Среднее | Upcoming + вероятность |
| PandaScore / авторы датасета | Лицензия | Среднее | Attribution, без HLTV scrape |

## Роли

1. **PM + интеграция** — документы, Compose, приёмка, защита.
2. **Data/ML** — датасет, признаки, обучение, Python-job.
3. **Backend (Go)** — схема БД, Gin, чтение прогнозов.
4. **Frontend** — UI (с недели 7).

## RACI

| Работа | PM | ML | Go | UI |
|---|---|---|---|---|
| Устав и PM-доки | A/R | C | C | I |
| Данные и лицензии | A | R | C | I |
| Схема БД | C | C | A/R | I |
| Обучение модели | I | A/R | I | I |
| Sync/predict job | C | A/R | C | I |
| REST API | C | I | A/R | C |
| Веб-интерфейс | C | I | C | A/R |
| Docker-демо | A/R | C | C | C |
| Защита | A/R | C | C | C |

R — делает, A — отвечает, C — консультирует, I — знает.
