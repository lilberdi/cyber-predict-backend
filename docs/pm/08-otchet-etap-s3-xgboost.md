# Отчёт по этапу S3: XGBoost и прогноз реальных матчей

**Проект:** Cyber Predict — прогнозирование матчей CS2 · **Дисциплина:** Управление проектами · **Дата:** 15 октября 2026
**Дисклеймер:** прогнозы учебные, не ставки и не финансовые рекомендации.

## 2. Как анализируются реальные матчи (схема для слайда)

```
PandaScore API ─ раз в час ─▶ фильтр топ-60 ─▶ PostgreSQL (matches, teams)
                                                    │
        история матчей (обучение) ─▶ признаки ─▶ XGBoost ─▶ predictions (вероятность + SHAP)
                                                    │
                                   Go/Gin REST ─▶ Vue frontend / Swagger
```

1. **Источник.** Официальный API PandaScore, раздел CS2. HLTV не используется (запрет в ToS).
2. **Фильтр.** Берём матчи, где есть хотя бы одна команда из рабочего списка топ-60 (свой список, не рейтинг HLTV). Из 66 полученных матчей оставлено 11.
3. **Признаки** считаются только по матчам до даты игры (защита от утечки данных).
4. **Модель.** XGBoost выдаёт вероятность победы команды 1; результат усредняется по двум расстановкам команд, чтобы убрать смещение «первый слот».
5. **Если истории мало** (меньше 10 матчей у менее известной команды), вероятность приближается к 50%, уверенность ставится «низкая». Так мы не изображаем знание там, где его нет.

## 3. Метрики, по которым прогнозируем

| Признак | Смысл | Доля в важности XGBoost |
|---|---|---|
| `elo_diff` | разница рейтинга Elo | 33% |
| `form10_diff` | разница винрейта за 10 матчей | 16% |
| `form5_diff` | то же за 5 матчей | 13% |
| `h2h_diff` | личные встречи за 12 месяцев | 13% |
| `tier` | тир турнира (S…D) | 9% |
| `exp_diff` | разница числа сыгранных матчей | 8% |
| `best_of` | формат серии (BO1/3/5) | 8% |

Не используются: счёт и результат самого матча, статистика игроков после игры (утечка).

## 4. Результаты модели

Хронологический тест: обучение на первых 80% матчей (720), проверка на последних 20% (180). История: 900 синтетических матчей.

| Модель | Accuracy | Log-loss | Brier |
|---|---|---|---|
| Elo (всегда фаворит по Elo) | 64,4% | 0,662 | 0,233 |
| Logistic regression | 62,8% | 0,658 | 0,231 |
| **XGBoost (рабочая)** | 61,7% | 0,660 | 0,234 |

**Честный вывод.** XGBoost не обгоняет простое Elo: разница в 2–3 п.п. находится в пределах шума на 180 матчах. Причина понятна: исходы в синтетической истории сгенерированы только по рейтингу команд, поэтому дополнительные признаки (форма, тир, опыт) не несут реального сигнала. На реальных данных ожидается выигрыш от них. Для CS2 55–65% считается нормальным уровнем. Гиперпараметры XGBoost подбираются на отдельной части обучающей выборки, тест не используется при подборе.

## 6. Что показать на защите (демо 5 минут)

1. Слайд со схемой из раздела 2 и словами про легальный источник.
2. Swagger (`/swagger/`): `GET /api/v1/matches/upcoming` — видно `source: pandascore`, вероятности, `top_features` с вкладом признаков.
3. `GET /api/v1/model/metrics` — таблица сравнения моделей, важность признаков.
4. Vue-интерфейс (когда будет готов): список матчей, полоса вероятности, «почему такой прогноз».
5. Честный слайд: XGBoost пока не лучше Elo, причина — синтетическая история; план — реальный датасет.

## 7. Изменения в рисках

| Риск | Статус |
|---|---|
| R6 Модель не лучше Elo | реализовался на синтетике; Elo остаётся fallback (`elo_sync`) |
| Новый: команды из PandaScore без истории | прогноз сжимается к 50%, уверенность «низкая», в ответе есть пояснение |
| Новый: CORS при подключении Vue | настроить `CORS_ORIGIN` на адрес dev-сервера Vue (например `http://localhost:5173`) |
