# Отчёт по этапу S4: реальные данные и честная оценка модели

**Проект:** Cyber Predict — прогнозирование матчей CS2 · **Дисциплина:** Управление проектами · **Дата:** 16 октября 2026
**Дисклеймер:** прогнозы учебные, не ставки и не финансовые рекомендации.
**Этот отчёт заменяет метрики из отчёта 08:** там модель училась на синтетике, здесь на реальных матчах.

## 1. Что сделано на этапе

| № | Задача | Результат |
|---|---|---|
| 1 | Реальная история матчей | 9 950 завершённых матчей CS2 из официального API PandaScore (26.02–15.10.2026, 933 команды). Загрузка: 100 запросов, 97 секунд, команда `python -m ml ingest-past` |
| 2 | Накопление истории | Воркер раз в 6 часов подгружает новые результаты, раз в сутки переобучает модель |
| 3 | Новые признаки | Форма с затуханием, отдых между матчами, средняя разница по картам. Каждый проверен отдельным экспериментом |
| 4 | Калибровка вероятностей | Реализованы Platt и isotonic, метод выбирается на отдельной части данных, ECE и таблица надёжности в метриках |
| 5 | Честная оценка | Walk-forward по 5 временным окнам, 95% доверительные интервалы (bootstrap), отдельная оценка по командам с историей |
| 6 | Факт против прогноза | Эндпоинты `/matches/finished` и `/model/live-accuracy`: считают точность по матчам, прогноз на которые сохранён до старта |

Вся история взята через официальный API по токену проекта. HLTV не используется.

## 2. Данные для обучения

| Параметр | Значение |
|---|---|
| Источник | PandaScore API, `csgo/matches/past`, CS2 (title 13) |
| Объём | 9 950 матчей после очистки (из 10 000 полученных убраны неполные, технические поражения и ничьи) |
| Период | 26 февраля — 15 октября 2026 |
| Команд | 933 |
| Разбиение | хронологическое: первые 80% (7 960 матчей) на обучение, последние 20% (1 990) на тест |

Объём выбран осознанно: всего у PandaScore 45 тысяч матчей CS2, мы взяли ~10 тысяч самых свежих. Для учебного проекта этого достаточно, а нагрузка на ноутбук минимальная (обучение вместе со всеми проверками занимает около 5 секунд).

## 3. Признаки (10 штук)

| Признак | Смысл |
|---|---|
| `elo_diff` | разница рейтинга Elo |
| `form5_diff`, `form10_diff` | разница винрейта за 5 и 10 последних матчей |
| `h2h_diff` | личные встречи за 12 месяцев |
| `exp_diff` | разница числа сыгранных матчей |
| `best_of` | формат серии |
| `tier` | тир турнира (S…D) |
| `ewm_form_diff` | форма с затуханием: свежие матчи весят больше |
| `rest_diff` | разница дней отдыха с последней игры (максимум 30) |
| `margin_diff` | разница средней разницы по картам за 10 матчей |

Все признаки считаются только по матчам до даты игры; это проверено тестами.

## 4. Результаты

### 4.1. Тестовая выборка (1 990 матчей)

| Модель | Accuracy | Log-loss | Brier |
|---|---|---|---|
| Elo (всегда фаворит по Elo) | 61,8% | 0,653 | 0,231 |
| Logistic regression | 61,5% | 0,652 | 0,230 |
| **XGBoost (рабочая)** | **61,9%** | **0,639** | **0,224** |

### 4.2. Walk-forward: 5 окон, обучение на прошлом и проверка на следующем периоде

| Модель | Accuracy (среднее ± разброс) | Log-loss |
|---|---|---|
| Elo | 60,6% ± 1,8 п.п. | 0,662 |
| Logistic regression | 61,0% ± 1,5 п.п. | 0,657 |
| **XGBoost** | **61,9% ± 1,6 п.п.** | **0,652** |

XGBoost лучше обоих baseline в среднем по окнам и по log-loss, и по accuracy.

### 4.3. Значимость результата

95% доверительные интервалы на тесте:

| Величина | Оценка | 95% интервал |
|---|---|---|
| Accuracy XGBoost | 61,9% | 59,9% … 64,1% |
| Accuracy Elo | 61,8% | 59,8% … 63,9% |
| Разница XGBoost − Elo | +0,15 п.п. | −1,7 … +1,9 п.п. |

**Вывод.** По числу угаданных матчей XGBoost статистически не отличается от Elo: интервал разницы включает ноль. Заметное преимущество у XGBoost в **качестве вероятностей**: log-loss 0,639 против 0,653 и Brier 0,224 против 0,231. Модель точнее оценивает, насколько уверена, хотя не чаще угадывает победителя. Честный итог для защиты: на текущем объёме данных мы **не доказали**, что XGBoost угадывает чаще Elo.

### 4.4. Вклад новых признаков (ablation, walk-forward)

Прирост log-loss и accuracy, который даёт признак (положительное значение — признак помогает):

| Признак | Прирост log-loss | Прирост accuracy |
|---|---|---|
| `exp_diff` | +0,0024 | +0,5 п.п. |
| `margin_diff` | +0,0018 | −0,04 п.п. |
| `tier` | +0,0010 | +0,3 п.п. |
| `rest_diff` | +0,0006 | +0,2 п.п. |
| `ewm_form_diff` | +0,0005 | +0,4 п.п. |
| `best_of` | +0,0002 | +0,4 п.п. |

Каждый новый признак чуть улучшает вероятности, ни один не даёт большого скачка. Сильнейший сигнал по-прежнему рейтинг Elo (22% важности в модели).

### 4.5. Калибровка

| Вариант | Log-loss | Brier | ECE (ошибка калибровки) |
|---|---|---|---|
| Без калибровки | 0,639 | 0,224 | 0,030 |
| Platt | 0,640 | 0,225 | 0,037 |
| Isotonic | 0,640 | 0,224 | 0,022 |

Метод выбирается автоматически на отдельной части обучающих данных, тест в выборе не участвует. Выбран вариант «без калибровки»: XGBoost с логистической функцией потерь и так хорошо откалиброван. Таблица надёжности (на тесте): когда модель говорит 65%, команды выигрывают в 62,5% случаев, при 74% — в 77%, при 83% — в 84%.

### 4.6. Команды с историей

Для пар, где у обеих команд есть хотя бы 10 матчей (1 445 из 1 990 тестовых): Elo 62,2% accuracy, XGBoost 60,9%; по log-loss XGBoost снова лучше (0,650 против 0,654). Разница в accuracy в пределах шума.

## 5. «Факт против прогноза»: проверка модели в бою

Теперь система сама проверяет себя на реальных матчах:

- каждый прогноз сохраняется до начала игры;
- воркер подтягивает результаты, и матч становится `finished` с победителем;
- `GET /api/v1/model/live-accuracy` отдаёт долю верных прогнозов, в том числе по уровню уверенности и по модели;
- `GET /api/v1/matches/finished` отдаёт список сыгранных матчей с полями `prediction_correct` и `winner_team_id` для интерфейса.

Прогнозы, посчитанные после старта матча, и ровные 50/50 в статистику не попадают. Счётчик начинает копиться с 16 октября 2026, поэтому на дату отчёта выборка мала. К защите, если воркер работает, накопится десятки матчей, и эту цифру можно показать как независимую от обучающей выборки проверку.

## 7. Что говорить на защите

1. **Данные.** Реальные 9 950 матчей CS2 из официального API, а не синтетика. Легально: HLTV не используем.
2. **Модель.** XGBoost на 10 признаках, подбор параметров без доступа к тесту, калибровка проверена.
3. **Результат.** 61,9% accuracy и лучшие вероятности (log-loss 0,639 против 0,653 у Elo). Для CS2 55–65% считается нормой.
4. **Честность.** Преимущество XGBoost над Elo по числу угаданных матчей статистически не доказано (доверительный интервал включает ноль). Мы показали это сами, с интервалами.
5. **Проверка в бою.** Система сохраняет прогнозы до матча и сама считает точность по сыгранным, цифра растёт каждый день.
6. **Ограничения.** История 8 месяцев; нет данных о составах и картах на free-плане; большая часть матчей в истории — турниры низких тиров; команда без истории получает прогноз около 50%.
